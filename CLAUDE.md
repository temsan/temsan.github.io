# ArtLanding — лендинг «Слепок мышления»

Одностраничник Артёма Бирюкова: услуга по созданию интеллектуальных систем на основе
мышления человека или компании. Статика без сборки — три файла и всё.

- **Публикуется** на GitHub Pages: `origin` → `temsan.github.io`, живёт на https://temsan.github.io/
- **Приватный спутник:** `../ArtLanding_inner` (github.com/temsan/ArtLanding_inner) — черновики
  кейсов, позиционирование, деловой контекст. Всё, что не готово к публикации, лежит там.
  Смысловой контекст проекта — в `ArtLanding_inner/CONTEXT.md`, читать вместе с этим файлом.

## Как устроено

```
index.html   разметка целиком, секции идут сверху вниз
styles.css   стили, переменные в :root
app.js       живопись на canvas + поведение страницы
```

**Публикация — только по прямой просьбе.** Пуш в `origin` делает страницу общедоступной,
сам не коммить и не пушь.

## Правила вёрстки

- **Одна колонка на всех ширинах.** `.wrap` = 720px, сетки везде `grid-template-columns: 1fr`.
  Это осознанное решение (коммит «Single-column layout»), не забывай и не «чини» его.
- **Шапка шире колонки:** `.site-header .wrap` = 900px. Пунктов меню больше, чем влезает
  в 720px, — при добавлении нового пункта проверь, что логотип не слипся с первым пунктом.
- Палитра — переменные в `:root`: ультрамарин `--ultra`, охра `--ochre`, сиена `--sienna`,
  льняные тона `--linen*`. Новые цвета берутся оттуда, а не изобретаются.
- Фон секций чередуется: `--linen-2` → умолчание → тёмный. Секция кейса намеренно тёмная.
- Комментарии в коде — по-русски, объясняют **почему**, а не что. Держись этого тона.
- При правке `styles.css`/`app.js` подними версию в `?v=N` у обоих тегов в `index.html`,
  иначе у посетителей останется старое.

## Живопись на canvas

`createPainting(canvas, options)` в `app.js` — общий движок для героя и блока CTA.
Палитры `DEEP` и `AIR` (ультрамарин, кобальт, церулеум + охра как рефлекс).
У героя `interactive: true` — картина дописывается под курсором.
Хук `onPaint` зовётся, когда живопись готова.

### Заливка заголовка (блок `inkHeadline`)

Буквы залиты **самой живописью**, попиксельно: берётся копия холста, у каждого пикселя
правится светлота и (если нужно) поворачивается тон, результат обрезается по контуру букв.
Разметка заголовка остаётся текстом — на canvas только заливка, для поиска и скринридеров
всё на месте. Если canvas-фильтры недоступны, тихо возвращается прежний `mix-blend-mode: difference`.

Текущие значения подобраны вживую и вшиты: `INK_MODE = 'screen'`, `HUE_SHIFT = 0`,
`sat 0.95 · lift -0.1 · contrast 0.2 · alpha 1`. При нулевом сдвиге буквы берут собственный
тон холста, а отделяет их от фона только светлота. **Механика поворота тона осталась
неиспользуемой** — если решено, что она не нужна, `shiftPixels` можно сильно упростить.

### ВРЕМЕННОЕ: панель настройки

Блок `tunePanel` в `app.js` — ползунки, открывается адресом `?tune`. На обычной странице
её нет. Когда параметры окончательно устроят, блок удаляется целиком вместе с шапкой
комментария «ВРЕМЕННОЕ», а значения переносятся в константы выше.

## Грабли, каждая стоила времени

1. **`destination-in` режет на каждый вызов отрисовки.** Маска из нескольких строк текста
   даёт пустое пересечение: после первой строки остаются её буквы, после второй —
   пересечение с ней. Собирай маску целиком на отдельном холсте и применяй одним `drawImage`.
2. **`hue-rotate` в CSS и canvas — линейная матрица, а не поворот по цветовому кругу.**
   На насыщенных цветах уводит тон и обесцвечивает. Нужен честный поворот — считай через HSL.
3. **Чистым CSS сдвиг тона поверх `difference` не сделать:** поворот не меняет серую ось,
   поэтому для белого источника сдвиг математически сокращается. Только canvas.
4. **Подсветка активного пункта меню** не может опираться на долю высоты секции: при
   `rootMargin` рабочая зона наблюдения — считанные сотни пикселей, и высокие секции порог
   не набирают никогда. Сейчас активна секция, пересекающая центр экрана (`threshold: 0`,
   `rootMargin: -49% 0 -49%`). До этой правки «Продукты» не подсвечивались вовсе.
5. **Локальная проверка:** браузер кэширует не только ассеты, но и сам `index.html`.
   Поднимай `python -m http.server 8899` и открывай с мусорным параметром: `?nc=1`, `?nc=2`.
   Иначе увидишь старую версию и будешь искать несуществующий баг.

## Что не проверено

Мобильная вёрстка вживую не смотрелась: `resize_window` в браузерном инструменте
не срабатывал, `innerWidth` оставался прежним. Правила под телефон дописаны, но глазами
никто не видел — при случае открой на настоящем телефоне.
